# React - The Complete Guide

This repository contains the projects and exercises developed while studying **React** through the course *React - The Complete Guide*, by Maximilian Schwarzmüller.

The main goal of this repository is to document my learning process and provide a practical reference for the concepts, patterns, and tools covered throughout the course.

Each project focuses on different aspects of the React ecosystem, progressively introducing new concepts and techniques. As I complete new sections of the course, this README will be updated with an overview of the projects, the concepts covered, and the technologies used.

## Repository Goals

* Build a solid understanding of React fundamentals.
* Practice React through multiple hands-on projects.
* Explore common patterns and best practices.
* Become familiar with the React ecosystem and its most relevant tools.
* Document my progress and consolidate what I learn through practical implementation.

## Technologies

The repository will primarily use:

* React
* JavaScript
* HTML
* CSS
* Vite
* Redux
* React Router
* TypeScript
* Other tools and libraries introduced throughout the course.
